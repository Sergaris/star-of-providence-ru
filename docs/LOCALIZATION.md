# Руководство по локализации Star of Providence

Русский язык в игре занимает слот **ZHS** (колонка `ZHS` в CSV, пункт «русский» в меню). Ниже — ограничения движка, проверенные в игре; их нарушение даёт пустой текст, обрезку или краши.

## Обязательное требование: режим 8px

После выбора **«русский»** в меню языка игрок **обязан** выбрать **8px** (не 16px) в том же меню. Это не рекомендация, а условие корректной работы перевода.

![Обязательная настройка 8px](images/8px-russian-setting.png)

Без **8px** возможны: обрезка текста, пропадание цен в магазине Kleines, сбои отображения кириллицы.

## Формат файлов

| Правило | Значение |
|--------|----------|
| Кодировка | UTF-8 с BOM (`utf-8-sig`) |
| Колонка перевода | **ZHS** (8-я колонка данных) |
| Разделитель | Запятая; в колонке **Comments** не вставляйте запятые без кавычек |
| ID | Числовой `ID` в первой колонке; после обновления Steam: `patch.py init --force` |

## Теги и разметка

Скопируйте набор тегов из колонки **EN** один в один. `patch.py validate` сравнивает теги, переменные и число `#`.

| Тег | Назначение |
|-----|------------|
| `#` | Перенос строки |
| `##` | Жёсткий разрыв абзаца |
| `/c0` … `/c5` | Цвет |
| `/f0`, `/f1` | Вариант шрифта |
| `/p1`, `/p2` | Пауза в диалоге |
| `%name%`, `%nr%` | Подстановки как в EN |

## Шрифт

- В игру ставится `fonts/NotoSans-ExtraBold.ttf` вместо `Chusung-220206.ttf` (`install_patch.bat`).
- Noto шире пиксельного шрифта: длинные строки в узком UI обрезаются по ширине в пикселях.
- **Не сокращайте** названия предметов, боссов, режимов и языков ради меню.

## Цена в магазине Kleines

**Файл:** `localization/kleines_caption.csv`  
**Строка:** `ID = 9`  
**ZHS (рабочий вариант):** `#/p2/c1цена` → в игре: `ЦЕНА , 75,000 G.`

Игра **не хранит** цену в CSV. Суффикс `, NNN G.` дописывается сразу после префикса из id 9.

### Ограничение буфера

Видимая часть префикса (без тегов `#/p2/c1` и т.п.) — **не более 10 байт в UTF-8**.

| ZHS | UTF-8 | Результат |
|-----|-------|-----------|
| `#/p2/c1цена` | 8 | **рекомендуется** — русское «цена» + сумма |
| `#/p2/c1isso dá` (PT) | 8 | аналог для португальского слота |
| `#/p2/c1that'll be` | 10 | англ. фраза; при Noto/16px сумма может пропадать |
| `#/p2/c1стоит` | 10 | сумма часто **не видна** |
| `#/p2/c1: ` | 2 | цена видна, но без слова «цена» |

`patch.py validate` предупреждает, если префикс длиннее 10 байт UTF-8.

## Подписи клавиш (обучение)

**Файлы:** `keyboard_keys.csv`, `keyboard_keys_switch.csv`

Подсказки в обучении («ЛКМ», «Tab», «Л. Shift») берутся из этих CSV, а не из `ui_strings`. Без патча в слоте ZHS остаётся китайский из оригинала (`鼠标左键` и т.п.). `install_patch.bat` копирует оба файла вместе с остальной локализацией.

## Диалоги и UI

- Длинные реплики: `scripts/fix_linebreaks.py` (не трогает `kleines_caption` id 9).
- Не используйте `fix_ui_overflow.py` — скрипт удалён; не укорачивайте «продолжить», «музыка» и т.п.

## Обновление Steam

1. `python scripts/patch.py init --game-path "..."` (без `--force`, если в репозитории уже есть русский ZHS; `--force` затирает непереведённые строки английским)
2. Перевести новые строки (ZHS == EN — непереведённые)
3. `python scripts/patch.py validate`
4. `install_patch.bat`

Для отката перевода: Steam → Свойства игры → Проверить целостность файлов (см. README).

## Скрипты

| Скрипт | Назначение |
|--------|------------|
| `scripts/patch.py` | init, stats, validate, check-release |
| `scripts/fix_linebreaks.py` | переносы `#` в длинных строках |
| `scripts/configure_russian_defaults.py` | опционально для разработки: kleines, 8px в save |
| `scripts/build_release.ps1` | сборка zip для GitHub Release (bat + localization + fonts) |

## Типичные симптомы

| Симптом | Решение |
|---------|---------|
| Краш при выборе русского, index 84 | Добавить id 84–85 в `option_caption.csv` |
| `стоит ,` без суммы | ZHS id 9 → `#/p2/c1цена`, режим **8px** |
| Обрезанные подписи меню | Перенос `#`, не бессмысленные сокращения |
| Пустые реплики NPC | Переустановить патч (`install_patch.bat`) |
| Вернуть оригинал | Steam → Свойства → Проверить целостность файлов |
